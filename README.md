# HC International Digital Agency

Premium editorial-style agency website built with Next.js.

## Stack
- Next.js 15 App Router
- React 19
- CSS motion and responsive layouts
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Notes
- The portfolio cards are illustrative concept directions, not verified client case studies.
- The contact form is front-end only and does not transmit or store submitted data. Replace with an approved form endpoint before using it to collect enquiries.
- Photography is loaded from Unsplash image URLs.
